# Heart_Failure_Prediction
Heart Failure 30-Day Readmission Prediction

A machine-learning classification project comparing Logistic Regression, K-Nearest Neighbors (KNN), and Decision Tree models to predict 30-day readmission.

Dataset: 12,000 records
Target: Readmitted_30_Days
Final model in the reported experiment: Logistic Regression

See README.md for methodology, evaluation metrics, setup instructions, and limitations.
